# Contributing to AxLab

The goal is **independent replication**, not a scoreboard of unverified claims.

Include your hardware/software manifest, exact command and source revision, raw JSON outputs, number of repetitions, and any unexpected behavior. If a test reports 0 runtime errors but fewer tasks than events, explain the accounting rather than concluding no work was lost.

Only run experiments on devices you own or are authorized to test. Never upload private prompts, customer content, secrets, or API keys.
