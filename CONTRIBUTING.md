# Contributing to AxLab

The goal is **independent replication**, not a scoreboard of unverified claims.

Include your hardware/software manifest, the exact command and source revision, raw JSON outputs, the number of repetitions, and anything unexpected. If a test reports 0 runtime errors but fewer tasks than events, explain the accounting rather than concluding no work was lost.

Only run experiments on devices you own or are authorized to test. Never upload private prompts, customer content, secrets or API keys.

## Code and research contributions

Run `pytest` before opening a pull request. New research tracks follow [docs/ADDING_RESEARCH.md](docs/ADDING_RESEARCH.md).
